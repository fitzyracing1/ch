C-COMPUTER

16-bit register machine. Only legal arithmetic is C = m · c / d. Reset is every 0 in binary.

0000000000000000
m=0 c=0 d=0 C=0 pc=0 hyp=1 halted=false
Cycle: predict d from hypothesis · compute C · push before the plant moves · correct hyp from real echo.
d = 0 or NaN forces C to every 0 in binary. Source: c_computer.py
